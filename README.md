# Fundamentos de Desarrollo Web – Código del curso

Repositorio con todo el código HTML y CSS del curso introductorio de desarrollo web para estudiantes de secundaria.

## ¿Cómo uso este repositorio?

**No necesitas instalar nada.** Tienes dos opciones:

1. **Opción fácil (recomendada):** abre los enlaces de JSFiddle que aparecen en `course-plan.md`. Ya traen el código precargado y no necesitas registrarte.
2. **Opción manual (si prefieres otro editor, como CodePen o Replit):** abre cualquier archivo de `starter-files/` aquí en GitHub y cópialo en tu editor. Hay dos casos:
   - **Si tu editor tiene paneles separados para HTML y CSS**, copia el código que está **dentro de `<body>`** en el panel HTML (el editor agrega el `<head>` y el `<body>` por ti). Si hay un archivo `style.css`, cópialo en el panel CSS.
   - **Si tu editor trabaja con archivos**, crea un `index.html` y un `style.css` y copia cada archivo completo.
   - ¡Listo! Verás el resultado al instante.
